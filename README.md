Contact Book App 📒

A simple beginner-friendly Contact Book application built using Python.

Features

- Create a contact
- View a contact
- Update a contact
- Delete a contact
- Search for a contact
- Count total contacts
- Exit the application

 Contact Information

Each contact contains:

- Name
- Age
- Email
- Mobile number

Technologies Used

- Python
- Dictionary
- While loop
- Conditional statements
- User input

How to Run

Make sure Python is installed on your computer.

Run the following command in the terminal:

```bash
python Contact_Book.py


Purpose

This project was created to practice Python fundamentals, including dictionaries, loops, conditional statements, user input, and basic CRUD operations.
